본 보고는 두 가지 데이터 작업의 과정·방법·기술적 의사결정을 기록한다. (A) KCI 피인용(cited_by) 데이터 정제 — 오염된 저널 필드를 art_id 기준으로 복원. (B) KRI 연구자정보 수집 — 논문 저자를 국가연구자번호로 연결해 소속·전공·학위를 수집.

A. KCI 피인용 데이터 정제 (cited_by)

A-1. 문제 발견

피인용 목록 cited_by의 각 항목은 {art_id, 저자, journal, …} 구조인데, 다저자 인용 논문에서 공저자 이름이 journal(저널명) 칸으로 밀려 들어간 파싱 오염이 발견됐다. 즉 저널명 자리에 사람 이름이 들어 있다.

예시 — 논문 ART002602737: journal="권미경"(실제로는 공저자 이름), journal="안광열" 등. 인용한 쪽(references)은 정상(art_id 대조 98.1% 일치)이라 cited_by만 문제.

A-2. 진단 — “복구 가능한가”를 데이터로 확인

  • art_id 100% 보유 — cited_by 260,537개 항목 전부가 정상 art_id를 가진다. 오염된 문자열을 버리고 art_id로 저널·분과를 재조회하면 복구 가능하다는 근거.
  • 오염률 직접 측정 — 인용 논문이 우리 코퍼스(A11) 내부에 있으면 진짜 저널명을 알 수 있다. 이 144,275개를 ground truth로 대조하니 오염률 13.4%(19,355건). 사용자가 본 예시 논문은 41.7%였는데, 이는 다저자 인용이 몰린 이상치였음을 확인.
  • 재조회 규모 산정 — 고유 art_id 85,376개 중 내부 35,287(즉시) / 외부 50,089(KCI 재조회 필요).

A-3. 해결 방법 — art_id 기준 재도출 (4단계)

① 진단·규모 산정→ ② 내부 즉시 복구 144,275칸→ ③ 외부 50,089 KCI 재조회→ ④ 분과 매핑·저장
  • 원본 보존 원칙 — 원본 journal은 절대 수정하지 않고, journal_clean·분과 필드를 신설.
  • 내부: art_id가 코퍼스에 있으면 즉시 진짜 저널명 대입. 외부: KCI 상세페이지를 art_id로 조회(로그인 불필요)해 저널·발행기관 확보 → 캐시·재개·레이트리밋.
  • 분과 매핑: 확보한 저널명을 학술지종수.xls(KCI 전체 6,339종)에 한글명·영문명·ISSN 다중키로 매칭.

B. KRI 연구자정보 수집

B-1. 목표

논문 저자를 국가연구자번호(kri_num)로 식별해, KRI(한국연구자정보)에서 소속·직급·전공분야·출신학교·취득학위를 수집한다. 이는 “소속 분과는 X인데 타 분과 학술지에 내는” 미포섭 분석의 기반 데이터다.

B-2. 핵심 발견 — kri_num은 KCI 안에 있었다

KCI 연구자 페이지(poCretDetail)의 onclick fncArtiSelectCitationIdx('CRT…','<kri_num>') 두 번째 인자가 곧 국가연구자번호다. 우리가 이미 가진 crt_id로 이 페이지를 열면 kri_num을 공짜로 수확할 수 있다 → kri_num 수확 단계엔 2FA 불필요(KCI 자동 로그인).

B-3. 파이프라인

1a 공저자 cret 수집→ 1b kri_num 수확 (KCI)→ 1c 매핑 테이블→ 2 KRI 연구자정보 (2FA)

B-4. 방법론적 난관과 해결 (과정의 핵심)

  • “crt는 있어도 kri가 없는” 연구자 — KRI 미등록자는 정상적으로 kri_num이 없다(6,103건). 이를 no_kri로 분기 처리(오류 아님)해 헛 재시도·오판을 제거.
  • 과거 버그의 정체: 잘못된 페이지 — 7필드의 정답 페이지는 PG-RP-102(기본정보 조회). 과거엔 PG-RP-101의 IBSheet 그리드를 긁어 헤더 텍스트만 따왔던 것. 본수집 전 10명으로 셀 구조를 덤프해 확정.
  • 세션 만료(2FA) — KRI 세션이 만료되면 재로그인에 2FA가 필요. 밤샘 무인 수집을 위해 절전 방지 + 연속 활동 + 체크포인트 재개 + 드라이버 자동 재시작을 적용.
  • 비공개 연구자 — 정보 공개 거부자(628명)는 alert 처리해 private로 기록하고 계속 진행.
