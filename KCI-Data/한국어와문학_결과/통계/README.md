# 한국어와문학 데이터셋 — 통계 (2008~2024)

대상: `../korlit_2008_2024.pkl` (= `../korlit_2008_2024.csv`), **총 52,068편**, 한국어와문학(A11) 115개 학술지.
산출일 기준 스냅샷. 모든 표는 UTF-8(BOM) CSV.

## 핵심 수치
- **총 논문 수**: 52,068편 (2002~2026 (대부분 2008~2024))
- **학술지**: A11 분류 115종 (데이터상 journal_ko 표기 139종 — 학술대회 자료 등 포함)
- **피인용**: 합계 288,219회 · 평균 5.54 · 중앙값 3 · 최대 290 · 1회 이상 피인용 44,303편
- **참고문헌**: 총 1,433,916건 (논문당 평균 27.5건, 그중 KCI 등재논문 354,362건)
- **피인용 목록**: 총 260,537건 (논문당 평균 5.0건)
- **인용 네트워크 엣지(추정)**: 약 614,899개 (참고문헌 내 KCI논문 + 피인용목록)
- **공저 논문 비율**: 9.9% (단독저자 90.1%)

## 주의
- **저자별 통계 미제공**: 데이터에 저자 이름만 있고 KCI 저자 고유번호(KRI)가 없어, 동명이인이 한 명으로 합쳐짐(예: '김영주' 187편 = 소속 42개 = 여러 명). 정확한 저자별 집계는 KRI ID 재수집 후에만 가능. (논문당 저자 '수' 분포는 `09_저자수분포.csv` 참고.)
- **피인용/참고문헌**은 수집 시점 KCI 기준. 최근 논문은 피인용 목록이 미확정일 수 있음(횟수 > 목록).
- **DOI 미보유**(구논문)는 빈 값 — 결측 아님.
- 피인용 백분위(p50~p99): {'p50': 3.0, 'p75': 7.0, 'p90': 13.0, 'p95': 18.0, 'p99': 34.0}
- 자세한 컬럼 정의는 `../COLUMNS.md` 참고.
