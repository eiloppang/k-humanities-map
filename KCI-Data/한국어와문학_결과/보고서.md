# 한국어와문학 논문 데이터셋 — 보고서

## 1. 개요

- **연구분야**: 인문학 > 한국어와문학 (KCI 분야코드 **A11**) — **전체 115개 학술지**
- **수집 대상 기간**: 2008년 ~ 2024년 발행 논문
- **출처**: KCI(한국학술지인용색인, www.kci.go.kr)
- **수집일**: 2026-06-04
- **최종 논문 수**: **52,068편**
- **목적**: 인용현황(참고문헌 + 피인용)을 포함해 **한국문학의 지평도(인용 네트워크)** 를 그릴 수 있는 데이터 구축

학술지 목록은 KCI 분류검색(`ciSereClasList`, 한국어와문학 A11)에서 추출한 **115개 학술지**(`journals_a11.csv`)를 기준으로 하며, 각 학술지의 고유 식별자(sereId)로 논문을 정밀 수집했습니다.

## 7. 인용 네트워크(지평도) 구성법

- **노드**: 각 논문 `article_id` (ART…)
- **나가는 엣지** (이 논문 → 인용 문헌): `references` 중 `art_id` 보유분 (KCI 내부 인용, 약 35.4만)
- **들어오는 엣지** (이 논문 ← 인용한 논문): `cited_by`의 `art_id` (약 26.1만)
- 두 방향을 합쳐 `article_id` 간 방향 그래프 → 한국어와문학 인용 지평도.

```python
import pandas as pd
df = pd.read_pickle("korlit_2008_2024.pkl")
edges = []
for _, r in df.iterrows():
    for ref in r["references"]:                 # 나가는 엣지
        if ref.get("art_id"): edges.append((r["article_id"], ref["art_id"]))
    for cb in r["cited_by"]:                     # 들어오는 엣지
        if cb.get("art_id"): edges.append((cb["art_id"], r["article_id"]))
# edges → networkx 등으로 그래프 구성
```

## 8. 방법론 / 주의사항

- **학술지 범위**: KCI 분류검색(ciSereClasList)의 한국어와문학(A11) **전체 115종**을 기준으로 함.
- **정밀 식별**: 학술지명(SERE_NM) 검색은 유사명 저널까지 반환하는 퍼지매칭이라 결과가 부풀려짐(예: '한국언어문학' 검색 총 19,772건 중 실제 해당지 891건). 분류검색의 **고유 sereId**가 논문검색 결과행의 sereId와 일치함을 검증하고, 그 sereId로 **정밀 필터**하여 동명이저널(예: 어문연구 2종)까지 정확히 구분.
- **한자/영문 등재명 학술지 복구**: 등재명이 한자(예: 國語學, 漢字漢文敎育)인 학술지는 한글 이름검색으로 0건이 나와, KCI 분류검색의 sereId 기반(이름 무관) 열거(연도→호→논문)로 **별도 복구**함(국어학 663, 한자한문교육 404, 한국어와 문화 20 등 +1,087편).
- **0건 8종**: sereId 기준으로도 2008~2024 등재논문이 없는 학술지(휴간·신생·영문지 등) — 정상.
- **최근 논문 인용목록**: 최근 발행 논문의 `cited_by`는 인용지수 공개 후 확정되므로 `cited_count`보다 짧거나 빌 수 있음.
- **DOI**: DOI 미부여 구논문은 빈 값.
- **로그인 수집**: 참고문헌·피인용 목록은 KCI 로그인 후에만 노출되므로 인증 세션으로 수집.
