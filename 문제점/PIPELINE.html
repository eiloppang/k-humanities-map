한국 인문학 분과 미포섭/수입 분석 — 파이프라인 문서

대상: 「한국 인문학 학술 지형도 구축」(한국연구원 위탁). 본 문서는 분석 파이프라인의 개념·실행 순서·입출력·분과 확장 방법을 기록한다. 방법론 배경은 분과미포섭_분석프레임.md, 설정값은 config.py 참조. 현재 1차 적용 분과 = 한국어와문학(A11).

이 문서는 작업과 함께 갱신되는 살아있는 문서다. 마지막 갱신 2026-06-23. 변경 이력은 §8.

1. 개요 — 무엇을 하는 파이프라인인가

한 분과(예: 한국어와문학)의 KCI 논문이 분과 경계와 맺는 관계를 두 축으로 측정·시각화하고, 리포트(HTML/DOCX/XML)와 브라우징 아카이브(HTML)로 산출한다.

  • (I) 수입(참조): 이 분과 논문이 밖에서 무엇을 끌어오는가 (나가는 인용 기준). — 미포섭이 아니라 '빌림'.
  • (II) 미포섭: 이 분과에 잡히지 않는 것 = ①내용 불일치(실은 타 분과 논문) + ②영향 수출(타 분과가 인용).

2. 핵심 개념·방법론 (확정된 수정 반영)

2-1. 방향 정의 (모든 표·수치의 기준)

  • 수입(import) = 이 논문/저널이 타 분과를 인용 (references, 나가는 인용).
  • 수출(export) = 타 분과가 이 논문/저널을 인용 (cited_by, 들어오는 인용).

2-2. escape 점수 = surprisal

논문의 인용 분과 분포 Q에 대해 escape = Σ_(f≠home) Q_f · (−log P_f). P는 분과 전체의 평균 인용 분포, −log P_f는 분과 f를 인용하는 사건의 '뜻밖임(정보이론 surprisal)'. 흔한 월경(→교육학)은 자동 할인, 드문 월경(→사회·철학)은 가중. 계보: Rao–Stirling 다양성·Uzzi 비전형성. 합성식은 본 과제용 구성물.

2-3. 머리(head) 선별 — 4중 필터 교집합

필터기준(config)근거
증거충분매핑 인용 ≥ N_FLOOR(5)분포 추정 신뢰성
상대극단escape ≥ 상위 (1−PCTL)=10%'미포섭=평균보다 더 벗어남'은 상대 개념, 코퍼스 무관 스케일
응집최대행선지 ≥ COH_MIN(20%) 그리고 ≥ DEST_N_MIN(3)편다리(지속 천착) vs 산란 구분
타당분과행선지 대분류 ∈ PLAUSIBLE(인문·사회·예술·복합)공학·의약 고응집은 데이터 오염 → 워크리스트로 분리

2-4. 4유형 — 행선지 분과 + 응집도로 구분

유형축판별 기준의미
이론월경수입행선지=사회·철학·심리·정치·법·여성학 (중간 응집)그 분과 이론·방법으로 문학 해석(렌즈 차용)
비교언어수입행선지=중·일·영·불 문학·통번역·언어학문학 내 측면 이동(비교·번역)
융복합교육수입행선지=교육·문헌정보·사전·학제간어문 연구의 교육·응용 확장
내용분과미포섭행선지=예술·종교, 응집 ≥50% + 초록 내용어 확인실은 그 분과 논문이 어문지에 게재
핵심 수정(대화 중 확정): 이론월경·비교언어·융복합교육은 '미포섭'이 아니라 수입(참조)이다. 한국문학 논문이 이론을 빌린 것일 뿐 게재지·대상은 문학. 미포섭은 내용 불일치(내용분과)+영향 수출로 한정한다. 응집도가 '빌림'과 '실제 그 분과임'을 가른다.

2-5. 내용 불일치 판정 — 인용 응집 + 초록 교차검증

  1. 인용이 한 외부분과(예술·종교)에 CONTENT_COH(50%)+ 응집한 논문을 1차 식별.
  2. 초록에 그 분과 내용어(config.MARK; 불교→禪·수행·경전)가 있는지로 교차검증. — 한국어와문학 결과: 검증가능 47편 중 33편(70.2%) 확인.

2-6. 초록 변별어 — Fightin' Words(컷오프 없음)

kiwipiepy 명사(NNG/NNP) 추출 + 불용어(config.STOP) 제거 후, Monroe et al. 2008 분산가중 log-odds z-score로 내용분과 vs 이론월경 직접 비교. 희소어는 큰 분산으로 자동 수축 → 빈도 컷오프 불필요(저빈도 잡음 자동 제거).

2-7. 영향 수출 — 외부 피인용 vs 전체 피인용

cited_by를 분과로 환원해 외부 피인용(비-home 분과로부터)과 전체 피인용(KCI 총합, home 포함)을 분리. 영향 '수출'은 외부 피인용 기준으로 본다. 주의: cited_by의 journal 필드 오염(§6)으로 외부 피인용은 현재 하한.

5. 다른 분과 적용 가이드 (사·철·예)

파이프라인 구조는 동일. config.py의 분과 의존값 교체 + 해당 분과 데이터 준비가 핵심이다.

5-1. config.py에서 교체할 항목

항목의미분과별 작업
HOME / BASE / PKL분과명·경로·수집 데이터분과별 KCI 수집 후 경로 지정
TYPE_FIELD행선지 분과→유형분과마다 '내용분과'가 다름 → 재정의

임계값(N_FLOOR 등)머리 선별대개 그대로, 분포 보고 조정

5-2. 분과별 주의

  • 인지거리 P는 자동 재계산되나, 입력이 그 분과 데이터여야 한다(거리는 분과 상대값).
  • C/D(이론 수입·저자 궤적) 는 현대문학 전용 자산(KLS_Reference·한국문학.pkl)에 의존. 타 분과는 해당 분과의 정제 참고문헌·KRI 연계가 선결.
  • 미완: 현재 스크립트는 값이 하드코딩. 확장 전 각 스크립트가 config.py를 import 하도록 리팩터링 필요(§8-1 함수화의 마지막 단계).

6. 알려진 데이터 품질 이슈

  • cited_by journal 필드 오염(수출 쪽): 다저자 인용 논문에서 공저자 이름이 journal 칸으로 밀림(예 ART002602737: 164건 중 81건). → 외부 피인용 과소집계(하한). 복구: 모든 cited_by에 art_id가 있으므로 art_id로 저널·분과 재조회(KCI). (정제팀 전달 완료)
  • references(수입 쪽)는 정상: art_id 대조 일치율 98.1%. 불일치 1.9%는 한자↔한글 표기 변이뿐 → 정규화만(낮은 우선순위).
  • 미매핑: 저널→분과 매핑에 없는 인용. 위 오염 + 비-KCI·해외 저널. 보고서·아카이브에 '하한' 명시.
